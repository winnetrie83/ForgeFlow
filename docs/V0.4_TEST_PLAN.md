# ForgeFlow v0.4 visual & input regression checklist

Test under Qt Creator / Qt 6.11.2 or newer on Windows. The GUI cannot be executed in the packaging environment.

1. Select **Smelter**, place it on two different empty cells with two separate left clicks. Tool stays active, ghost follows cursor, both remain placed. Right-click cancels; next left click inspects an existing machine.
2. Choose **Conveyor**. For each R rotation (N/E/S/W), compare cyan arrow to physical model length and with the expected flow. After placement the physical belt must lie in the same orientation as the ghost.
3. Hold **Shift** while moving to the destination cell. Preview a horizontal line eastwards and westwards and vertical lines northwards and southwards; click once to place. The line direction and arrow direction should be identical before/after placing. Verify consecutive separate lines can be drawn without reselecting Conveyor.
4. By default no port/arrow markers should appear on existing buildings. Toggle **F3**: all placed buildings must show their logical ports; toggle again to hide. All build ghosts must show their ports even when F3 is off.
5. Build preview ports: Miner output only (orange); Smelter input green opposite output orange; Storage input green only; Conveyor both plus flow arrow.
6. Check that the Miner uses the crane body and **no magnet attachment**. Confirm model is not excessively large, floating or rotated relative to the output marker.
7. Demo → Play: production and storage counters still increase. Inspect storage, save/load, demolition, camera controls, occupied cells, and right-click cancel still function.

Known limitations: prototype remains 1×1 logical footprints for all structures, including scaled-down crane; automatic conveyor turns and multi-cell buildings are not implemented. Visual mesh alignment can still depend on original Kenney model orientation and must be verified in the 3D Qt view.
