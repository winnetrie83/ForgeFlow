# ForgeFlow v0.3 acceptance checklist

1. Qt Creator / Qt 6.11.2: CMake configure → Build → Run (Windows validation required).
2. `X` or sidebar DEMOLITION TOOL enters demolition; hover existing building shows red highlight.
3. Left-click hovered occupied cell removes exactly one building. Empty cell changes nothing.
4. Right-click cancels demolition without removing anything; X toggles it off as well.
5. Conveyor ghost direction matches placed conveyor direction in all four cardinal directions.
6. Shift + move from an initial anchor produces a straight line and correct rotation in all four directions.
7. Cyan overlay shows conveyor item flow; green rear input / orange front output on machines.
8. Demo → Play → Storage counter increases; wrong-side Smelter input rejects ore.
9. Save, Clear, Load preserves building kind, cell and direction.
10. Toggle direction markers off/on; Kenney colors and camera controls remain functional.

Engine regression test (without Qt):
`cmake -S . -B build-core -DFORGEFLOW_BUILD_GUI=OFF && cmake --build build-core && ctest --test-dir build-core --output-on-failure`
