# v0.5 visual acceptance tests

1. Open Qt Creator / CMakeLists.txt, build, run. Click Demo: this version starts running automatically.
2. After ~2 seconds, check that an amber cargo cube travels over belts adjacent to miner. After processing, cyan cargo travels toward storage; Storage should increase.
3. Select Conveyor, rotate R 0/90/180/270. For every orientation, compare LONG axis of ghost belt with cyan arrow and with placed belt (must be parallel).
4. Test Shift-line preview and placed belt orientation in all four directions.
5. F3 enabled: compare output of miner, input and output of smelter, input of storage and conveyor flow.
6. If no item arrives, check Play/Pause indicator and inspector for miner stock, belt contents, smelter ore/bars, and storage bars.

Note: core CTest covers all 4 compass directions but cannot assert the rendered 3D mesh rotation.
