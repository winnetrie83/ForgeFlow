# ForgeFlow v0.2 Windows GUI acceptance checklist

Test with Qt 6.11.2 MinGW 64-bit and a fresh CMake build directory.

- [ ] CMake configure works without `QT_RESOURCE_ALIAS` absolute-source errors.
- [ ] Startup loads Main.qml without `letterSpacing` errors.
- [ ] Demo shows colored Kenney Factory Kit models; if still white, record Qt RuntimeLoader logs and GPU vendor.
- [ ] Clicking Smelter tool produces ghost; right-click on map removes ghost but does not erase buildings.
- [ ] Valid left-click placement builds one machine and exits build mode.
- [ ] Left-click the demo Storage building while idle shows inspector with iron-bar count.
- [ ] Play increases Storage iron-bar count in inspector without reselecting.
- [ ] Inspect Miner, Smelter and Conveyor to verify type-specific inventory/detail fields.
- [ ] Hold Shift with Conveyor selected, move cursor, click to build full line and exit build mode.
- [ ] Rotate view and middle-drag horizontally and vertically; report directional inversion if any.
- [ ] Right-drag rotates camera without deleting structures.
- [ ] Erase mode left-click deletes a building; normal right-click never deletes.
- [ ] Save/Clear/Load works; inspector closes after Load/Clear.

Note: Qt GUI was unavailable in the build environment; only platform-independent core unit tests have been run here.
